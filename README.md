## Overview

**OpenRecorder** is a lightweight still in progress **Recording Software** for quick recording sessions. More akin to a 4 track recording, OpenRecorder contains only the bare minimum to make recordings, ideal for beginners or those who like that vintage feeling of recording with limited hardware.

---

## Features

### 🎹 MIDI & Composition Tools

* Piano roll editor
* Drum pattern designer

### 🎚 Built-in Audio Suite

* Parametric EQ

### ⚡ Performance Optimized

* Uses the bare minimum to work

# Quick Start

### Create Your First Project

```powershell
# Launch OpenDAW and set workspace
./OpenRecorder ~/Documents
# or
./OpenRecorder ~/Desktop 
```

### Recording Audio

1. Create project from the console like instructed
2. Connect your audio interface
3. Select input device in **Preferences**
4. Arm the track for recording
5. Press **R** to record

### Exporting

```text
File → Export → WAV / MP3 / FLAC
```
